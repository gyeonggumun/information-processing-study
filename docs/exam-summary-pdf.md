# 실기 핵심 요약 PDF 갱신

실기 요약 페이지의 **내 요약 PDF 받기**는 버튼을 누른 시점에 내 계정 목록에 남아 있는 카드를 개인 순서대로 담아 브라우저에서 PDF를 생성합니다. 삭제된 카드는 제외하며 현재 과목 필터와 관계없이 전체 남은 목록을 사용합니다. 계정 설정을 불러오는 중이거나 저장 중이거나 남은 카드가 없으면 다운로드 버튼을 비활성화합니다.

기존 `public/downloads/exam-summary-quick-review.pdf`는 공통 자료의 보관본으로 유지되지만 페이지의 개인 다운로드에는 사용하지 않습니다. `exam-summary-atlas.pdf`와 `exam-summary-atlas.json`은 한글을 포함한 카드별 조판 자료입니다. 브라우저는 선택한 카드 조각만 새 PDF에 삽입하며, 다른 카드의 본문을 잘라 숨기는 방식이 아닙니다. 공통 학습 자료 자체는 기존 웹 데이터·PDF와 마찬가지로 공개 자산이며, 개인별 삭제·순서 설정은 내보내기 서버로 전송하거나 공유 파일에 저장하지 않습니다.

계산 부록은 남은 관련 카드에 맞춰 포함합니다. CPU 카드의 공통 계산 자료가 남으면 전체 예제, 비선점 시간축 카드만 남으면 FCFS·SJF·HRN, 선점 시간축 카드만 남으면 SRTF·RR을 사용합니다. 서브넷 주소·서브넷 분할·페이지 교체 예제도 해당 카드가 남아 있을 때만 포함합니다. 여러 카드가 같은 예제를 사용하면 한 번만 넣습니다.

생성 중 중복 클릭을 막고 오류를 안내합니다. 로그아웃·계정 변경·페이지 이동 시 작업을 취소하며 이전 계정의 PDF를 뒤늦게 내려받지 않습니다. PDF 도구는 다운로드 시점에 지연 로딩합니다.

## 구성

- `examSummaryCardIds` 기본 카드와 학습하기에서 직접 추가한 세부 학습 카드의 핵심 용어와 비교 노트
- 학습 모달과 같은 데이터로 만든 CPU 스케줄링 시간축·평균 계산
- 서브넷 분할·브로드캐스트 주소 및 FIFO/LRU 계산 예제
- 과목명이 표시된 카드별 책갈피, 계산 예제 책갈피, 페이지 번호와 자료 기준일
- 악성코드 종류와 구별, 보안 공격 유형, OTP·OAuth·SSO·ISMS 비교
- 릴레이션·튜플·속성·도메인·카디널리티·차수, 스키마·인스턴스·데이터 독립성, ER 구성·관계·참여 제약, NULL 비교

데이터베이스 기본 용어는 각 카드의 비교 노트에 예제를 함께 정리합니다. 릴레이션의 카디널리티(현재 행 수)와 ER 관계의 카디널리티(연결 수), 스키마와 인스턴스를 구별합니다. ER 관계는 [IBM ERD 설명](https://www.ibm.com/think/topics/entity-relationship-diagram), NULL 비교는 [PostgreSQL 공식 문서](https://www.postgresql.org/docs/current/functions-comparison.html)를 참고했습니다.

악성코드는 전파·위장·피해 행동이라는 서로 다른 분류 기준을 비교합니다. 바이러스·웜·트로이목마와 스파이웨어·백도어·논리 폭탄의 설명은 [NIST CSRC 용어집](https://csrc.nist.gov/glossary)에서 해당 정의를 확인해 작성했습니다. 기존 보안 세부 자료의 랜섬웨어·루트킷·키로거는 악성코드 카드로 모았으며, 원래 개요와 세부 카드 ID는 유지합니다.

## 다시 생성하기

Python에 `reportlab`과 `pypdf`가 필요합니다. 한글을 지원하고 PDF 임베딩이 허용되는 TTF 글꼴의 일반·굵은 파일을 지정하세요. Windows 기본값은 맑은 고딕입니다.

```powershell
node scripts/build-exam-summary-pdf.mjs --python "Python 실행 파일 경로" --font "일반 글꼴.ttf" --bold-font "굵은 글꼴.ttf" --date YYYY-MM-DD
```

공통 PDF와 개인 조판 자료는 `output/pdf/`에 생성되고 다운로드 폴더에도 복사됩니다. 개인 조판 자료만 갱신하려면 `--atlas-only`를 붙입니다. 웹 빌드에서는 조판 자료를 배포하고 다운로드 시 브라우저에서 재배치하므로 운영 환경에 Python이나 글꼴 설치는 필요하지 않습니다.

자료를 수정한 경우 PDF를 다시 생성하고, 전체 페이지를 이미지로 확인한 뒤 조판 자료도 함께 커밋합니다. 생성기는 모든 용어가 PDF 텍스트에 포함되는지 확인하며, PDF 생성 실패 시 기존 다운로드 파일은 갱신하지 않습니다. `npm run build`는 먼저 원본 카드·자료 버전·파일 해시의 일치를 검사해 오래된 조판 자료의 배포를 막습니다.

`npm run verify:summary-pdf`는 순서·숨김 제외·계산 부록 선택·자료 버전 불일치·취소·실제 파일 생성을 검증하고 `output/pdf/`에 확인용 샘플을 만듭니다. 기본키 같은 공통 용어가 남은 카드의 설명에 등장할 수는 있지만 삭제한 카드의 본문은 삽입하지 않습니다.

## 학습하기에서 개인 카드 추가 (2026-10-18)

Pro·Admin 계정의 과목별 세부 학습 카드에 `실기 요약에 추가` 버튼을 제공합니다. 기본 116개는 유지하며, 전체 세부 학습 269개 중 선택한 카드만 개인 목록 끝에 추가합니다. 전체 개요 카드는 중복 내용이므로 추가 대상으로 삼지 않습니다. 이미 담은 카드는 추가됨으로 표시하고, 삭제한 카드는 학습 페이지에서 다시 추가하면 원래 개인 순서로 복원합니다.

새 DB 테이블이나 권한 변경 없이 `exam_summary_preferences.card_order`와 `hidden_card_ids`를 사용합니다. 기본 목록과 추가 가능한 목록을 구분하여 저장된 추가 카드를 재조회 때 제거하거나, 선택하지 않은 카드를 자동으로 추가하지 않습니다. 기존 순서·삭제 설정과 계정별 RLS·현재 로그인 세션 검증을 유지합니다. User 계정에는 버튼을 표시하지 않고 요약 설정 조회도 시작하지 않습니다. 저장 실패 시 변경을 되돌리고 다시 시도할 수 있습니다.

개인 PDF 조판 자료는 추가 가능한 269개 카드 모두를 지원하지만, 다운로드 파일에는 본인이 남긴 카드만 포함합니다. 공통 요약 보관본의 기본 116개 선정은 변경하지 않습니다. `npm run verify:summary-additions`와 `node scripts/verify-exam-summary-preferences.mjs`로 실제 학습 컴포넌트의 권한별 버튼 표시, 선택 추가·중복 방지·복원·재조회·다른 계정 기본값 분리·PDF 연결을 검증합니다. 격리된 브라우저 저장소로 추가·삭제 후 재추가·저장 실패 롤백도 확인했으며 실제 사용자 설정을 테스트로 변경하지 않습니다.
