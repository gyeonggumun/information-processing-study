# 추가 요약자료 대조 및 학습 보강

## 범위와 선정 기준

- 제공받은 91쪽 PDF의 전체 텍스트를 추출해 기존 과목·세부 그룹·용어와 비교했습니다.
- 용어의 한글·영문 표기 차이를 고려하여 기존 내용을 그대로 복제하지 않고, 이름만 언급됐거나 설명이 부족한 부분을 보강했습니다.
- 새 세부 카드는 하나의 주제로 묶고 의미·상세 설명·예시·확대 가능한 SVG 도식을 제공합니다. 개발 기간과 메모리 배치는 별도 수치 도식도 제공합니다.
- 실기 요약은 기존 79개에 보강 카드 중 36개와 기존 교착 상태 카드를 더한 116개입니다. 출제 회차·빈도를 새로 집계한 결과가 아니며, 반드시 출제된다는 의미도 아닙니다.
- 제공 PDF의 원문·이미지·전체 추출문은 공개 저장소나 웹사이트에 올리지 않습니다. 개념을 이해한 뒤 새 문장과 예제로 작성했습니다.

## 함께 교정·보강한 내용

1. 기존 자료의 `조건/결정 커버리지 (MC/DC)` 표기를 C/DC와 MC/DC 두 항목으로 구별했습니다. 비교 노트와 PDF에도 같은 기준을 적용합니다.
2. 합쳐져 있던 점유와 대기·비선점을 분리했습니다. 네 조건의 동시 성립은 교착 상태의 **필요조건**이라는 표현으로 정리했습니다.
3. 페이지 교체 카드에 NUR/NRU의 참조·변경 비트와 2차 기회 알고리즘을 추가했습니다.
4. SHA-384·512의 출력은 각각 384·512비트입니다. 모두 256비트라는 제공 자료의 표현은 사용하지 않았습니다.
5. Node.js는 런타임, Spring Batch는 배치 처리 프레임워크이며 스케줄러 자체가 아닙니다.
6. DH는 키 합의입니다. 해시를 복호화 가능한 암호와 혼동하지 않으며 DES·RC4·MD5·SHA-1의 구형 용도도 명시했습니다.
7. 분산 DB의 중복·복제 투명성을 같은 개념으로 정리했습니다. NoSQL이 모두 스키마·조인·트랜잭션을 지원하지 않는다는 일반화는 피했습니다.
8. 즉시 갱신에서 모든 롤백이 UNDO·REDO를 모두 수행한다거나, 체크포인트가 항상 이전 시점으로 되돌리는 것이라는 표현은 피했습니다.
9. TLS 구성 설명은 버전 차이를 표시했습니다. TCP 윈도우의 RTT별 증가와 수신 윈도우·혼잡 윈도우를 구별했습니다.

오래된 공격 도구의 제품명, 드문 명명 사례, 일반 환경 범죄예방 용어(CPTED) 등은 실기 요약에 무조건 추가하지 않았습니다. 이 문서는 전체 공식 출제 범위를 빠짐없이 보장한다는 선언이 아닙니다.

## 호환성 및 검증

- 기존 카드 ID를 변경하지 않아 즐겨찾기와 개인 삭제·정렬 설정을 유지합니다. 새 요약 카드는 기존 개인 목록 뒤에 추가됩니다.
- `npm run verify:study-supplements`: 과목 연결, 그룹 분량, 설명·예시, SVG 항목, 요약 선정, 교정 항목, 계산값, 개인 설정을 검사합니다.
- `npm run pdf:summary`: 공통 PDF와 개인 PDF 조판 자료를 함께 갱신합니다.
- `npm run verify:summary-pdf`: 현재 카드 목록과 PDF 서명·개인 순서·삭제 제외·계산 부록 선정을 검사합니다.

### 실행 결과

- 카드 대조 검사와 개인 PDF 회귀 검사 통과. 공통 PDF는 21쪽·116개 카드·588개 용어로 갱신했습니다.
- 전체 PDF 페이지를 렌더링해 확인했으며 개인 PDF 22쪽의 글자가 페이지 경계를 벗어나지 않는지 검사했습니다.
- 실제 학습 컴포넌트의 DRM 빠른 요약·상세 도식, 분산 투명성 모바일 390px 표시, 메모리 배치 계산 도식을 확인했습니다.
- 검증용 계정 대역으로 실기 요약 116개 카드와 개인 PDF 다운로드를 확인했습니다. 실제 계정 데이터는 변경하지 않았습니다.
- 변경 파일 정적 검사와 운영 빌드 통과. 대형 JavaScript 청크 경고는 남아 있으며 이번 자료 보강과 무관한 코드 분할 작업은 하지 않았습니다.
