# 실기 유사 랜덤 문제 200문항

## 이용 경로와 구성

- 경로: `/similar-exams`
- 메뉴: 기출문제 → 실기 유사 랜덤 문제
- Pro·Admin 계정에 메뉴와 풀이 화면을 공개한다. User 계정으로 직접 접속하면 비공개 화면을 표시한다. 비로그인은 기존 로그인 경로를 따른다.
- 전용 문제은행: 이론·계산 50, C 40, Java 40, Python 40, SQL 30으로 총 200문항이다. 모든 항목을 섞어 한 문제씩 무작위 출제한다.
- 데이터: `similarExamTheory.js`, `similarExamCode.js`, `similarExamSql.js`를 `similarExams.js`에서 통합한다.

기존에 확보한 11회차 복원 자료의 핵심 개념·코드 연산에 근거를 연결했다. 프록시의 대리 접근, 추상 팩토리의 제품군 생성, 모듈 결합도·응집도, 커버리지·DB·서브넷·스케줄링과 C 포인터·구조체·재귀, Java 상속·오버로딩·열거형, Python 슬라이스·클래스·집합, SQL 조인·상관 질의·집계·뷰 등을 다룬다.

원문과 다른 사례, 식별자, 입력 데이터, 조건 또는 출력 선택 위치를 사용한다. 코드 템플릿별 5문항은 고정된 ID와 입력을 가지므로 무한 생성 문제가 아니다. 뷰 조회처럼 원문의 집계 연산을 결합·확장한 유형은 확장임을 해설에 밝힌다. 미래 출제나 공식 채점 결과를 보장하지 않는다.

## 풀이·복습 동작

기존 복원 페이지와 같은 필답형 자기채점 방식이다. 답안 작성 후 예시 답안·단계별 풀이를 공개하고 정답 또는 오답으로 기록한다. C·Java·Python에는 별도 주석 코드, SQL에는 JOIN·그룹·뷰의 중간 표 및 최종 조회 표를 제공한다. 문제를 풀기 전에는 개념 제목과 정답·해설·원문 링크를 노출하지 않는다.

일반·복원 문제와 겹치지 않는 `similar-` ID를 사용한다. 저장된 문제는 이후 랜덤 출제에서 빠지고, 오답노트에서는 같은 문제를 다시 풀 수 있다. 풀이 기록에서는 해설을 다시 열며 통계를 추가하지 않는다. 기존 기록을 초기화하지 않는다.

저장 유형은 기존 `exam`으로 통합하므로 기출문제 통계에 합산된다. DB 스키마 변경 없이 기존 계정별 기록 저장·읽기 정책을 사용한다. 새 페이지와 복습 패널 모두 기존 `ProtectedRoute`/역할 검사로 Pro 접근을 확인하며, 권한이 내려가도 문제·해설·자기채점 패널은 비공개로 전환한다. 문제 자료는 기존 서비스처럼 클라이언트 정적 데이터이며 다운로드 자체를 막는 서버 전용 콘텐츠 저장소를 도입한 것은 아니다.

복원 게시글 및 CC BY 4.0 출처는 해설에 표시하고 창작·변형한 사실을 함께 안내한다.

## 검증

`npm run verify:similar-exams`는 다음을 확인한다.

- 200개 ID·영역별 수량·문제 본문 중복·복원 근거·원문과 다른 코드
- 모든 항목의 랜덤 도달, 이미 기록한 문제 제외, 전체 완료, 현재 문제 건너뛰기
- 자기채점 저장 형식, 오답 재풀이 완료, 풀이 기록과 오답노트 연결
- SQL 30개 실제 실행, 빈칸 완성 SQL, 중간 JOIN·뷰 표 및 최종 결과 표
- Pro·Admin 허용, User·잘못된 권한·확인 중·비로그인의 제한, 200문항 풀이 전후 해설 렌더링

`node --experimental-sqlite scripts/verify-similar-exams.mjs --execute`는 추가로 Python 40개 실행, Java 40개 컴파일·실행, C 40개를 `-O0`와 `-O2`에서 실행해 정답을 대조한다. 실행에는 Python/JDK 및 기존 로컬 Zig 검증 도구가 필요하다.

브라우저 검증은 `scripts/serve-responsive-ui.mjs`의 격리된 화면을 이용한다. 이 화면의 기록은 브라우저 메모리에서만 처리하며 실제 인증·사용자 DB에 접근하지 않는다. 답안 입력→해설·표→오답 기록→다음 문제→오답 재풀이→완료와 역할 변경 후 비공개를 확인했다. 모바일 390px에서 문서 폭이 화면 밖으로 넘치지 않으며 코드의 가로 스크롤은 내부에 유지된다.
