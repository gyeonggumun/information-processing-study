# 문제 오타 검수

## 범위

현재·보관 문제 2,341개의 지문, 정답, 해설, 코드 및 복원 문제 표시 블록을 점검했다. 복원 원본 JSON과 문항 ID·계정별 풀이 기록은 보존한다. 화면에는 별도 보정 함수를 적용한다.

- `알맞는 → 알맞은`, `Pyhon → Python`, `평군 → 평균`, `속상이 → 속성이`, 따옴표·생략 오타, 중복 단어, 보이지 않는 문자를 보정했다.
- C 헤더·문자열 따옴표·세미콜론, Java 예약어·출력문·필드 접근, Python 문자열 결합의 자료형 오류를 보정했다.
- C 출력 서식에 맞는 형 변환을 명시하고, 삭제된 gets 대신 제시된 공백 없는 이름을 읽는 길이 제한 입력을 사용한다.
- SQL의 스키마·INSERT SELECT 열 불일치, 외래키 열 괄호, 문자열 따옴표, 예약어와 겹치는 표 이름을 보정했다.
- UNION 자료 표의 빠진 A 열 머리글과 관계대수 나눗셈 기호를 보완했다.
- 빈칸 정답은 채우지 않았다. Java 오류 찾기의 의도된 static 오류와 원문 줄 번호, 생성자 호출 순서의 ①~⑦ 표시는 유지한다.

현재 복원 표시 144문항에 원문 대비 보정이 적용되며, 그중 코드 블록 보정은 17문항이다. 이 수에는 기존 표시 보정도 포함한다. 이미지 원본과 문제의 수치·출력 정답은 바꾸지 않았다.

## 검증

```powershell
npm run verify:question-typos
node --experimental-sqlite scripts/verify-restored-walkthroughs.mjs --execute --display
```

- 지정한 오타·문법 패턴의 잔여 검출 0건. 모든 자연어 오타가 없다는 보장이 아니라, 확인한 오류의 회귀 방지 검사다.
- 실제 표시 코드의 C 41문항 O0/O2, Java 34문항, Python 15문항 실행 결과 확인. 빈칸은 테스트 내부에서만 채웠다.
- Java 의도된 컴파일 오류와 C 흐름도 문제는 별도로 취급한다.
- SQL 15문항과 보정한 스키마·외래키 정의를 메모리 DB에서 실행했다. 서비스 DB에는 접속하지 않는다.
- 기존 원문 보존·정답 공개 전 힌트 숨김·Pro 권한·이론 구별점 검사도 유지한다.
