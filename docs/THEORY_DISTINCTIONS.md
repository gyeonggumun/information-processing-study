# 실기 복원·유사 문제의 이론 구별점

- 복원 비코드 112문항 중 기존 구별점 19개 유지, 누락 93개 보강.
- 유사 이론·계산 50문항 중 기존 구별점 18개 유지, 누락 32개 보강.
- 보강 대상에는 `헷갈리기 쉬운 개념 구별`에서 용어의 뜻과 구별 기준을 함께 표시한다.
- 보기 기호·복수 답안·숫자 답안도 검수한 문항 ID로 연결한다. 답안 일부 문자열로 주제를 추측하지 않는다.
- 암호학적 해시와 자료구조 해싱은 서로 다른 설명을 연결한다. 외래키·도메인, 3NF·BCNF 등도 문항의 개념에 맞춰 비교한다.
- 기존 구별 설명은 중복하지 않으며 원문 문제·답안·코드 주석·풀이 기록은 바꾸지 않는다.
- 문제 패널에서 정답 공개 뒤에만 표시한다. 같은 패널을 쓰는 오답 복습·풀이 기록에도 적용된다.

검증: `npm run verify:theory-distinctions`, `npm run verify:reading-clarity`, 기존 복원·유사 문제 검사, lint·build.
125문항의 해설 공개 시점·Pro/Admin 및 User/미확인 권한 표시를 검사했다. 기존 구별점 37개와 코드 관련 258문항의 제외 여부도 확인했다.
모의 화면에서 제출 전 비공개·제출 후 표시 및 390px 모바일 화면의 가로 넘침 없음을 확인했다. 실제 사용자 데이터는 수정하지 않았다.
