# 1시간 비활동 자동 로그아웃

- 마지막 실제 활동부터 60분이 지나면 해당 브라우저의 Supabase 세션을 `signOut({ scope: 'local' })`로 로그아웃합니다. 다른 기기나 브라우저의 세션은 유지됩니다.
- 닉네임 오른쪽에 `60:00`부터 초 단위로 남은 시간을 표시하고, 5분 이하이면 강조합니다.
- 보이는 화면의 마우스 이동·클릭·키 입력·휠·터치가 활동입니다. 읽기만 하는 동안에는 시간이 줄어듭니다.
- 같은 브라우저의 같은 사용자·세션은 마지막 활동 시각을 공유합니다. 다른 사용자와 새 로그인 세션은 분리합니다.
- 새로고침, 탭 복귀, 토큰 갱신은 활동으로 처리하지 않습니다. 백그라운드·절전으로 타이머 실행이 늦어져도 실제 시각으로 만료를 판정합니다.
- 만료 시 보호 화면과 프로필 모달을 닫고 자동 로그아웃 안내를 표시합니다. 저장소 사용이 금지된 브라우저에서는 현재 탭의 메모리로 동작하므로 새로고침 간 시각 보존은 제한됩니다.

기존 사용자는 이 기능이 적용된 뒤 처음 세션을 읽을 때부터 활동 시간이 기록됩니다. 시간 표시만 별도 저장소를 구독하므로 전체 학습 화면을 매초 다시 렌더링하지 않습니다. 사용자 ID·세션 ID·활동 시각만 별도 저장하며 토큰이나 비밀키를 추가 저장하지 않습니다.

## 보안 범위

이 기능은 브라우저의 비활동 로그아웃 정책입니다. 브라우저 저장소를 직접 변조하거나 API를 직접 호출하는 클라이언트에 대한 서버 측 접근 차단을 대신하지 않습니다. 기존 RLS와 관리자 권한 검사는 유지됩니다. [Supabase 공식 로그아웃 문서](https://supabase.com/docs/reference/javascript/auth-signout)에 따르면 이미 발급된 액세스 토큰은 로그아웃 이후에도 만료 시각까지 유효할 수 있으므로, 서버 차원의 즉시 만료가 필요한 경우 별도의 세션 검증 정책이 필요합니다.

## 검증

`npm run verify:idle-session`으로 실제 1시간을 기다리지 않고 시간·활동·탭 공유·새 로그인·절전·저장소 오류·리스너 정리를 검증합니다.
