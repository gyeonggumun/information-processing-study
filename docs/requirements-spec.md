## 2. 서비스 개요

정보처리기사 실기 시험을 준비하는 사용자가 기출문제, 5과목 학습, C·Java·Python 코드 연습, 오답노트와 전체 학습 통계를 한곳에서 이용할 수 있는 웹 학습 플랫폼이다.

백준과 유사하게 상단에 주요 메뉴를 배치하고, 문제 풀이 중심의 밀도 있는 화면을 사용한다. 단, 백준의 로고·문구·세부 디자인을 복제하지 않고 독자적인 브랜드와 색상을 사용한다.

## 3. 사용자 목표

1. 사이트에 접속한 즉시 오늘 풀 문제를 선택한다.
2. `학습하기` 메뉴에 마우스를 올려 5과목 중 하나를 선택한다.
3. 과목 구분 없이 전체 기출문제를 순서대로 풀어본다.
4. C, Java, Python 중 원하는 언어를 선택해 코드 실행 결과 문제를 연습한다.
5. 틀린 문제를 오답노트에서 다시 확인한다.
6. 전체 학습률과 정답률을 통계 화면에서 확인한다.

## 5. 상단 내비게이션 요구사항

### 5.1 공통

- 상단 고정 헤더를 사용한다.
- 좌측에 서비스 로고와 서비스명을 표시한다.
- 주요 메뉴는 홈, 학습하기, 기출문제, 코드 연습, 오답노트, 통계로 구성한다.
- 현재 경로의 메뉴는 색상과 하단 테두리로 활성 상태를 표시한다.
- 데스크톱에서는 마우스 호버와 키보드 포커스로 하위 메뉴를 열 수 있어야 한다.
- 모바일에서는 햄버거 메뉴를 눌러 내비게이션을 연다.

### 5.2 학습하기 드롭다운

`학습하기`에 마우스를 올리면 다음 5과목이 표시된다.

1. 소프트웨어 설계
2. 소프트웨어 개발
3. 데이터베이스 구축
4. 프로그래밍 언어 활용
5. 정보시스템 구축 관리

각 항목에는 과목명, 간단한 설명, 색상 식별자를 표시한다.

### 5.3 코드 연습 드롭다운

`코드 연습`에 마우스를 올리면 다음 언어를 표시한다.

- C
- Java
- Python

## 6. 메인페이지 요구사항

### 6.1 첫 화면

- 서비스 목적을 한 문장으로 표시한다.
- `전체 기출 시작` 버튼을 제공한다.
- 전체 진행률, 정답률, 연속 학습일, 이번 주 풀이 수를 카드로 표시한다.

### 6.2 과목 학습 현황

- 5과목을 카드 형태로 표시한다.
- 각 카드에 과목명, 설명, 진행률, 학습 계속하기 링크를 표시한다.
- 카드를 누르면 해당 과목 페이지로 이동한다.

### 6.3 최근 학습 문제

- 최근 풀이 문제를 회차·문항 번호·분류·유형과 함께 표시한다.
- 완료 상태와 풀기 상태를 구분한다.
- 전체 기출 화면으로 이동할 수 있어야 한다.

### 6.4 집중 영역

- 5과목별 진행률을 막대 그래프로 표시한다.
- 상세 통계 화면으로 이동할 수 있어야 한다.

## 7. 기능 요구사항

### FR-001 과목 선택

사용자는 상단 `학습하기` 메뉴의 드롭다운에서 과목을 선택할 수 있어야 한다.

### FR-002 전체 기출 학습

사용자는 과목 구분 없이 전체 기출문제를 한 목록에서 확인할 수 있어야 한다.

초기 데이터 목표는 2022년 1회부터 2026년 2회까지 총 14회, 약 280문항이다.

### FR-003 기출 검색

사용자는 문제명, 키워드, 유형으로 전체 기출문제를 검색할 수 있어야 한다.

### FR-004 언어별 코드 연습

사용자는 C, Java, Python 탭을 선택할 수 있어야 한다.

### FR-005 오답노트

사용자는 틀린 문제의 수, 복습 완료율, 취약 영역을 전체 기준으로 확인할 수 있어야 한다.

### FR-006 통계

사용자는 전체 진행률, 전체 정답률, 학습 시간, 과목별 진행률을 확인할 수 있어야 한다.

### FR-007 반응형 화면

- 데스크톱: 상단 메뉴와 드롭다운 사용
- 태블릿: 메뉴 간격 축소 및 카드 2열
- 모바일: 햄버거 메뉴, 카드 1열, 가로 스크롤 없는 화면

## 8. 비기능 요구사항

### NFR-001 사용성

- 첫 화면에서 기출문제 풀이로 바로 이동할 수 있어야 한다.
- 메뉴명은 전문용어보다 수험생이 이해하기 쉬운 표현을 사용한다.
- 주요 본문 텍스트는 14px 이상을 권장한다.

### NFR-002 접근성

- 메뉴와 버튼은 키보드로 접근 가능해야 한다.
- 아이콘 단독 버튼에는 `aria-label`을 제공한다.
- 색상만으로 완료·미완료 상태를 구분하지 않는다.

### NFR-003 성능

- 초기 뼈대에서는 정적 JSON 데이터를 사용한다.
- 이미지 없이 CSS와 아이콘 중심으로 구성한다.
- Vercel 정적 배포를 고려하여 클라이언트 번들 크기를 관리한다.

### NFR-004 유지보수성

- 페이지, 공통 컴포넌트, 데이터 파일을 분리한다.
- 과목과 문제 데이터는 화면 코드와 분리한다.
- 문제 데이터에는 출처, 회차, 신뢰도 필드를 추가할 수 있어야 한다.

## 10. 현재 뼈대 구현 범위

현재 버전은 다음을 구현한다.

- React + Vite 프로젝트
- 상단 고정 메뉴
- 학습하기 5과목 호버 드롭다운
- 코드 연습 C·Java·Python 호버 드롭다운
- 홈 대시보드
- 5과목 학습 현황 카드
- 전체 기출 목록과 검색 입력
- 언어별 코드 연습 탭
- 오답노트 화면
- 전체 통계 화면
- 모바일 반응형 내비게이션
- Vercel 정적 배포를 고려한 구조

현재는 UI와 사용자 흐름을 검증하기 위한 샘플 데이터 단계이며, 실제 문제 280문항·해설·사용자별 저장 기능은 다음 개발 단계에서 연결한다.

## 11. 개발 단계

### 1단계: 화면 뼈대

- 상단 메뉴와 라우팅 구축
- 홈, 과목, 기출, 코드, 오답, 통계 페이지 구축
- 모바일 반응형 적용

### 2단계: 학습 데이터 연결

- 2022년 1회~2026년 2회 문제 입력
- 과목 및 태그 분류
- 정답·해설·출처 입력

### 3단계: 문제 풀이 기능

- 답안 입력
- 정답 비교
- 허용 답안 처리
- 문제별 완료 상태 저장

### 4단계: 오답 및 통계

- 오답 자동 등록
- 복습 완료 처리
- 과목별 정답률
- 회차별 점수
- 언어별 코드 풀이 통계

### 5단계: 사용자 계정 및 데이터베이스

- 로그인
- 사용자별 풀이 기록
- 여러 기기 간 동기화
- 관리자 문제 등록 기능

## 12. 완료 기준

- 상단 메뉴에서 모든 주요 경로로 이동할 수 있다.
- 학습하기 호버 메뉴에서 5과목이 표시된다.
- 코드 연습 호버 메뉴에서 C·Java·Python이 표시된다.
- 기출문제 화면은 과목 필터 없이 전체 문제를 표시한다.
- 문제 검색 입력이 동작한다.
- 모바일에서 메뉴가 깨지지 않는다.
- `npm run build`가 성공한다.
- 요구사항 문서와 프로젝트 구조가 일치한다.

## 13. 배포 계획

1. Git 저장소에 프로젝트를 등록한다.
2. Vercel에서 저장소를 연결한다.
3. 프레임워크를 Vite로 설정한다.
4. Build Command는 `npm run build`를 사용한다.
5. Output Directory는 `dist`를 사용한다.
6. 이후 Git push마다 미리보기 또는 운영 배포를 생성한다.

사용자별 기록, 로그인, 관리자 기능을 추가하는 시점에는 별도 데이터베이스와 인증 서비스를 연결한다.
