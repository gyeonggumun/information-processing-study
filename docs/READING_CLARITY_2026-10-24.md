# 학습·문제 해설의 설명 정리

## 참고 방식

사용자가 지정한 [정리 글](https://gall.dcinside.com/mini/board/view/?id=dataprocessing&no=154789)을 직접 확인했다. 용어마다 역할을 짧게 설명하고 관련 용어는 구별되는 기준을 제시하는 서술 방식을 참고했다. 게시글의 문장을 학습 자료에 전재하지 않았으며, 기존 서비스의 학습·비교 자료를 바탕으로 독립적인 설명을 작성했다.

게시글의 모든 정의를 검증된 사실로 취급하지 않는다. 특히 동치 분할을 단순한 출력 결과 비교로 설명하거나 외래키를 다른 테이블의 기본키만 참조하는 것으로 한정하지 않았다. DB 제약은 [PostgreSQL 문서](https://www.postgresql.org/docs/current/ddl-constraints.html), RIP·OSPF 구별은 [RFC 2453](https://www.rfc-editor.org/rfc/rfc2453.html)과 [RFC 2328](https://www.rfc-editor.org/rfc/rfc2328.html)을 함께 확인했다.

## 반영한 구조

`plainConceptNotes.js`에 69개 핵심 개념의 쉬운 정의와 구별 기준을 마련했다. 개념은 정확한 이름·명시적인 별칭으로만 연결한다. MAC 주소에 접근 통제 MAC 설명을 붙이거나, 복합 용어를 부분 문자열만 보고 판단하지 않는다. 알려진 한글 명칭이 있으면 영문 이름 옆에 함께 표시한다.

학습 빠른 요약은 여러 작은 상자 대신 **용어 / 뜻 / 구별점** 목록으로 읽는다. 상세 정리는 **뜻 → 예시 → 구별 기준**을 먼저 보여 주고, 기존의 원리·보충 설명은 펼쳐 볼 수 있게 남긴다. 핵심 용어 태그는 모바일에서도 여러 개를 한 줄에 배치해 본문까지의 불필요한 길이를 줄였다.

학습 정의·원리·예시를 삭제하지 않는다. 기존 5과목 377개 자료의 2,528개 항목을 보존하면서, 67개 개념이 개요·세부 학습 171개 항목에 연결된다. 나머지 개념도 명시적인 정답 별칭이 있는 문제 해설에서 사용할 수 있다. 기존 이해 설명 18개 주제·90개 용어도 유지한다.

일반 기출의 해설에는 일치하는 정답 용어를 **뜻 / 구별점**으로 정리하고 이어서 문제의 판단 이유를 보여 준다. 현재 일반 필답형 195문항이 이 설명에 연결된다. 복원·유사 문제에도 같은 렌더러를 사용한다. 코드의 출력 답안으로 개념을 추측해 붙이지 않는다.

C·Java·Python·SQL과 복원·유사 문제의 풀이 순서는 유지하되, 긴 설명을 짧은 문단으로 나누어 읽게 한다. 주석 코드와 계산 표는 그대로 유지한다. 정답 설명은 기존과 같이 제출 후에만 보여 주며, Pro 제한·채점·저장·오답노트 동작을 변경하지 않는다.

## 내용 보존과 검증

`readingPassages`는 두 문장 또는 일정 길이 이상이 된 지점에서 표시 구간만 나눈다. 문장을 고치거나 자동 요약하지 않는다. 분리한 구간을 이어 붙이면 공백·줄바꿈·숫자·기호를 포함해 원문과 동일해야 한다. HTML처럼 보이는 문자열도 일반 텍스트로 출력한다. 코드 블록에는 이 표시 변환을 적용하지 않는다.

검증:

- `verify:reading-clarity`: 숫자·음수·소수·IP·SQL·HTML·공백 보존, 별칭 오연결 방지, 실제 자료 연결 수
- `verify:study-concept-tables`: 전체 학습 항목의 정의·원리·예시와 기존 이해 설명 유지
- `verify:question-presentation`: 제출 전 정답·해설 비공개, 제출 후 모든 원문 해설 유지
- `verify:detailed-solutions`: 코드 주석·중간 계산·해설 유지
- `verify:similar-exams`: 유사 200문항의 Pro 제한·재풀이·해설 표시 유지
- `lint`, 운영용 빌드

격리된 브라우저에서 상세 정리·빠른 요약·프록시 해설과 모바일 390px의 글자 크기 및 가로 넘침을 확인한다. 이 작업은 웹 표시와 설명 보강이며, 기존 PDF 파일·정답 데이터·사용자 기록을 재생성하거나 초기화하지 않는다.
