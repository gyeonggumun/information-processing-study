## 제작 근거와 구분

기존에 수집한 2023년 1회~2026년 2회 복원 자료 11회차를 참고했습니다. 출처 목록은 [회차별 출처 문서](./실기-회차별-문제-출처와-검수.md)에 있습니다. 각 새 문항의 `examReferences`는 관련 유형을 비교할 복원 문항 ID입니다. 관련 개념의 연결이지 새 사례의 원문 출제 이력을 의미하지 않습니다.

원문을 그대로 재수록하지 않고 상황·값·테이블·조건을 바꾼 창작 연습입니다. 공식 기출 원문 또는 출제 확정 예상 문제로 표시하지 않습니다. 실제 복원 문제 220개는 변경하지 않았습니다.

일반 문제는 모두 직접 입력하는 필답형입니다. 설명은 정답 근거와 관련 개념을 함께 제공합니다. C·Java·Python은 출력 추적형이며 코드 주석과 단계별 풀이를 기존 화면에 연결합니다. SQL은 결과 작성형 및 빈칸 완성형으로 표·SQL·단계별 해설을 제공합니다.

## 기존 기능 보존

- 일반 필답형: 기존 361 + 신규 160 = 521문항.
- 각 언어: 기존 150 + 신규 40 = 190문항(하 60·중 65·상 65).
- 기존·과거 문항 ID를 유지하고 신규에는 `additional` 전용 ID를 사용합니다.
- 일반 기출 4과목 통합 랜덤 출제와 언어별 난이도 랜덤 출제에 자동 포함됩니다.
- 새 문제도 제출 후 일반 랜덤 후보에서 제외되며, 풀이 기록·오답노트에서 다시 볼 수 있습니다.
- 로그인·등급·실기 복원 접근 정책과 실제 계정의 풀이 데이터는 변경하거나 초기화하지 않았습니다.
