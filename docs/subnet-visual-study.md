# 서브넷 계산 시각 학습

2026-10-18: 학습 자료를 비트 표와 주소 구간 도식으로 보강했습니다.

- 새 세부 카드: `subnet-cidr-calculation--g6-p1` / 비트 표로 푸는 브로드캐스트와 수신 IP.
- 예제: 192.168.35.10/22, 192.168.10.77/26, 172.16.9.130/22.
- 각 옥텟을 자리값·마스크·원래 IP·변환 결과로 나눕니다. 네트워크 비트는 파랑, 호스트 비트는 주황이며 경계선·행 제목으로도 구별합니다.
- 마스크의 0 개수 → 호스트 0으로 네트워크 주소 → 호스트 1로 브로드캐스트 → 일반 호스트 범위 순서로 표시합니다.
- /27 두 개 분할은 빌리는 비트와 /28의 두 주소 구간을 시각화하고, 주어진 .82가 포함된 구간을 강조합니다.
- 기존 서브넷 전체 개요와 주소 관련 세부 카드, 빠른 요약·상세 정리에서 같은 시각 자료를 사용합니다. 기존 카드 ID·기본 실기 요약 목록은 유지합니다.
- 새 세부 카드는 Pro 이상 계정에서 개인 실기 요약에 추가할 수 있고, PDF 카드 조판 자료도 270개로 갱신했습니다. PDF는 카드의 요점을 담으며 웹의 예제 전환 기능 자체를 포함하지는 않습니다.

첨부 이미지의 계산 구조를 참고했으며, 영상 화면을 복제하지 않고 HTML 표로 새로 만들었습니다. /22의 마스크와 주소 수는 [RFC 1878](https://www.rfc-editor.org/rfc/rfc1878), 호스트 비트를 모두 1로 두는 브로드캐스트 개념은 [RFC 919](https://www.rfc-editor.org/rfc/rfc919)를 확인했습니다. 수신 PC의 IP와 브로드캐스트 목적지 IP는 구분하며 실제 전달에는 브로드캐스트 도메인·장비 설정이 영향을 줍니다.

검증: `npm run verify:subnet-visuals`에서 165개 IPv4 경계 조합을 BigInt 비트 연산으로 검산합니다. /31·/32 예외, 예제 수신 범위, 새 학습 카드·개인 요약 연결, 6개 서브넷 카드의 상세·요약 렌더링을 확인합니다. 브라우저에서 예제 전환·분할 강조와 390px 단일 열 비트 표 배치를 확인했습니다. 기존 앱의 320px 최소 너비는 변경하지 않았습니다.
