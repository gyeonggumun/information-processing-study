# 실기 복원 랜덤 문제

- 경로: `/restored-exams` (로그인 및 Pro·Admin 권한 필요)
- 진입: 기출문제 메뉴 → 실기 복원 랜덤 문제 또는 기존 기출문제 화면의 Pro 전용 링크
- 범위: 아래 11개 복원 게시글의 각 20문항, 합계 220문항. 이론·계산·C·Java·Python·SQL을 제외하지 않음.
- 공식 시험지나 공식 정답 공개본이 아닌 Life-Journey의 복원 자료. 원문이 실제 시험과 다를 수 있음.

## 구성과 채점

전체 220문항의 미풀이 문제 중 무작위 1문항 표시 → 필답형 답안 작성 → 정답·해설 확인 → 이용자가 정답/오답 기록 → 다음 랜덤 문제. 회차를 따로 선택하지 않으며 모든 회차·유형을 같은 후보군에 포함한다. 미채점 상태에서 다른 문제를 누르면 가능한 한 현재 문제와 다른 미풀이 문제를 선택한다. 모두 기록하면 완료 안내를 표시한다.

페이지 경로·메뉴 및 공통 복원 문제 패널에 Pro 이상 권한 검사를 적용한다. 풀이 기록·오답노트에서도 일반 계정은 복원 문제와 해설을 열거나 자기채점할 수 없으며, 기존 기록 자체는 삭제하지 않는다. 이는 기존 실기 요약과 같은 클라이언트 접근 제한이다. 문제 자료는 공개 정적 번들에 포함되므로 원문 파일의 다운로드 차단이나 DB의 문제별 등급 검증을 보장하지 않는다.

복수의 올바른 SQL, 집합의 원소 순서, 여러 유효 IP, 서술·표 답안을 단순 문자열 비교로 오판하지 않도록 **자기채점**으로 구성했다. 공식 점수·부분 점수를 산출하지 않는다. 제출 전에는 정답·해설 DOM을 렌더링하지 않는다. 브라우저 정적 데이터인 만큼 정답 비밀 유지가 필요한 평가·시험 용도로는 사용하지 않는다.

기존 `practice_attempts`에 `practice_type='exam'`, `question_id='past-연도-회차-q번호'`로 결과만 저장한다. 작성한 답안 원문은 저장하지 않는다. 기존 문제 ID와 충돌하지 않으며 일반 미풀이 출제에서 제외된다. 풀이 기록에서 해설을 다시 열 수 있고 오답노트에서 재풀이할 수 있다. 관리자 초기화와 기출문제 통계는 기존 공통 저장 흐름을 사용한다. DB 스키마·RLS·계정 권한·기존 기록을 변경하지 않는다.

## 주요 검수 사항

- 2023년 2회 4번: `INSTER`를 `INSERT`로 정정하여 예시 답안에 표시.
- 2023년 3회 5번: 개념 화살표 `→` 대신 실제 C 연산자 `->`를 예시 답안에 표시.
- 2023년 3회 12번: NAT의 풀네임을 `Network Address Translation`으로 정정. 포트 변환 설명과 PAT/NAPT의 관계 안내.
- 2023년 3회 17번: `laas`를 `IaaS`로 정정하고 외부 도안을 관리 범위 표로 대체.
- 2025년 1회 15번: 문장 커버리지 전체 경로에 초기화·루프 진입을 포함. 원문의 OR 조건으로 인한 범위 초과 위험 안내.
- 2024년 1회 6번·2026년 2회 20번: 표만으로 정규형을 확정할 수 없음을 밝히고 함수 종속 전제를 명시.
- 2024년 2회 11번: RIP 홉 수와 그림의 가중치 최단 경로를 구별.
- 2024년 2회 7번: AES 선정 절차 시작(1997)과 표준 확정(2001) 구별.
- 원문의 헤더 생략·문법 오타·타입 오류는 문항별로 안내. 코드 실행기를 제공하거나 원문 컴파일 성공을 보증하지 않음.

## 재현과 검증

`scripts/import-restored-exams.py --assets`는 표준 Python 라이브러리로 지정한 11개 URL만 읽어 정규화한다. HTML 캐시는 ignored `tmp/restored-exams/`, 배포 자료는 `src/data/restoredExamsSource.json`, 그림은 `public/restored-exams/`이다. 해설은 별도 `restoredExamSolutions.js`에서 관리한다. 새로 수집한 자료를 배포하기 전에는 내용·라이선스·오타·이미지를 다시 검수해야 한다.

외부 HTML·스크립트를 실행하거나 `dangerouslySetInnerHTML`로 삽입하지 않는다. 텍스트·코드·표를 React로 렌더링하고 그림은 검증한 로컬 파일로 제공하므로 CSP를 완화할 필요가 없다. CDN 임시 서명 쿼리는 배포 데이터에 저장하지 않는다.

검증 명령: `npm run verify:restored-exams`, `npm run verify:wrong-answers`, `npm run verify:practice-history`, `npm run build`.

복원 자료 검증에는 전체 220문항의 랜덤 선택 가능성, 풀이 중복 제외, 마지막 미풀이 및 전체 완료 처리, Pro·Admin 허용과 일반·미확인 권한의 문제·해설·오답 복습 차단을 포함한다.

운영 DB에서는 읽기 전용 카탈로그 조회로 `exam` 유형 허용, RLS 활성화, 본인 기록 SELECT/INSERT 및 현재 로그인 세션 정책을 확인했다. 브라우저 저장·복습 흐름은 실제 사용자 데이터를 변경하지 않는 가상 저장소에서 검증한다. 운영 계정의 쓰기·로그인 전 과정을 새로 시험한 것으로 해석하지 않는다.

브라우저에서는 빈 답안 제출 방지·제출 전 해설 미노출·자기채점 저장·풀이 기록 재열람(추가 저장 없음)·오답 재풀이 완료·미풀이 재진입·모바일 도표 로딩을 확인했다. 저장은 성공했지만 응답이 유실된 가상 상황에서도 동일 UUID 재시도 후 1회로 기록되는 것을 확인했다.
